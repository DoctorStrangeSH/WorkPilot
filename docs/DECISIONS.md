# Malenia — журнал архитектурных решений

## ADR-001: Основной браузер — Яндекс Браузер
**Статус:** принято.

Яндекс Браузер является основным браузером пользователя и первым целевым браузером для интеграции. Совместимость каждого механизма автоматизации должна быть проверена на установленной версии.

## ADR-002: Гибридная браузерная архитектура
**Статус:** принято.

Поддерживаются два режима:
1. текущий профиль пользователя — через разрешённый мост/расширение, без чтения или копирования секретов профиля;
2. отдельное окно и профиль Malenia — для изолированных автоматизированных задач.

## ADR-003: Максимальная автоматизация с контролем риска
**Статус:** принято.

Malenia должен самостоятельно выполнять максимально возможную часть повторяемой работы. Необратимые, финансовые, публичные и чувствительные действия требуют подтверждения пользователя. Все действия журналируются; должна быть доступна остановка.

## ADR-004: Поиск по фотографиям — два направления
**Статус:** принято.

Поиск должен охватывать:
- локальные и подключённые рабочие ресурсы, доступные пользователю;
- внешние трекеры через отдельные адаптеры и пользовательские сессии/API.

Для каждого источника проверяются разрешения, доступность и условия использования.

## ADR-005: Ограничение ресурсов — 16 ГБ RAM
**Статус:** принято.

Система проектируется для компьютера с 16 ГБ оперативной памяти и встроенной графикой. Тяжёлые модели не должны быть постоянно загружены. Resource Manager управляет параллельностью и режимами Normal/Economy/Emergency.

## ADR-006: Local-first и отсутствие обязательной платной модели
**Статус:** принято как принцип.

Базовое приложение и локальные функции не должны требовать платного API. Внешние модели и сервисы подключаются отдельно; возможные расходы должны быть явно показаны пользователю до использования.

## ADR-007: Секреты и авторизация
**Статус:** принято.

Malenia не извлекает и не копирует браузерные cookies, пароли или токены. Пользователь авторизуется в сервисах самостоятельно. Секреты интеграций хранятся в системном хранилище секретов, а не в репозитории или обычной базе приложения.

## 2026-11-12 — полное пространство имён Malenia

По запросу пользователя версия 0.3 использует новые имена пакетов, исполняемых файлов, переменных окружения, application/native-host ID и папку данных Malenia. Старые задания и вкладки не переносятся: пользователь сообщил, что сохранять их не требуется. Предыдущая политика совместимого переименования интерфейса отменена. При этом старые установленные файлы автоматически не удаляются.

Повторный запуск нового приложения активирует существующее окно. Агент получает порт до объявления готовности; чужой процесс при конфликте не завершается.
