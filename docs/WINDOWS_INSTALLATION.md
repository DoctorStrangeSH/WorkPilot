Malenia 0.6.0 — обновление и Шерлок

Закройте старую Малению и запустите Malenia_0.6.0_x64-setup.exe из нового комплекта.
Запустите агента, откройте «ИИ-модели», нажмите «Запустить Шерлока» или кнопку
скачивания выбранной модели. Приложение само установит недостающий официальный
движок (архив около 1,6 ГБ, минимум 4 ГБ места на время установки). Модель скачивается
отдельно по кнопке; основная — около 5 ГБ. Отдельно устанавливать Ollama не требуется.
Для интернета включите соответствующий переключатель в чате: в Bing отправится
только текущий вопрос. Модель получит выдержки поиска со ссылками, а не полные страницы.
Подробности и ограничения: LOCAL_AI.md. Данные установленной Малении сохраняются.

Malenia 0.3.0 — установка на Windows

1. Распакуйте весь архив. Запустите Malenia_0.3.0_x64-setup.exe.
   Установка выполняется для текущего пользователя.
2. Скопируйте папку Malenia-Browser-Bridge в постоянное место: после загрузки
   расширения не перемещайте эту папку, чтобы сохранить его ID.
3. Откройте страницу расширений Яндекс Браузера (browser://extensions).
   Включите режим разработчика, выберите «Загрузить распакованное расширение»
   и укажите папку Malenia-Browser-Bridge. Скопируйте ID появившегося расширения.
4. Запустите Connect-Browser.cmd. Вставьте ID своего расширения и нажмите
   «Подключить». ID не задан заранее: на каждом компьютере используется свой.
   Путь к хосту обычно определяется автоматически. Если нужно, выберите файл
   malenia-native-host.exe в папке установленной Malenia/resources.
5. Полностью закройте и снова откройте браузер. Запустите Malenia через меню
   «Пуск» или ярлык. Нажмите «Запустить агента», если он ещё не запущен.
6. Откройте нужную обычную HTTP(S)-страницу и в расширении нажмите
   «Поделиться вкладкой». Запись появится в разделе «Браузер» Малении.

Если расширение обновляется в прежней папке, нажмите «Обновить/Перезагрузить»
на его карточке. ID берите именно с этой карточки; не используйте чужой ID.
Для нескольких пользователей на одном ПК установку и регистрацию выполняют
отдельно в каждом аккаунте Windows. Мастер настраивает один ID на пользователя;
одновременное подключение нескольких разных расширений не поддерживается.

Connect-Browser.cmd и оба файла .ps1 должны оставаться рядом. Перед выполнением
регистрации мастер проверяет ASCII, известную SHA-256 и синтаксис PowerShell.
Ошибка проверки останавливает настройку: не запускайте старые временные скрипты.
Проверка файлов комплекта: SHA256SUMS.txt (сама сумма не является цифровой подписью).

Этот комплект содержит проверенную Windows-сборку 0.3.0. Последние локальные
прототипы разрешений в неё не входят. Задачи пока сохраняются в очередь;
автоматическое выполнение, чтение текста страниц и снимки экрана не подключены.
Расширение передаёт название вкладки и URL без query/фрагмента только по клику.
Профиль, cookies, пароли и история браузера не считываются.
