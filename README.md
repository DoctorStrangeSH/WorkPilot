# WorkPilot

**WorkPilot** — локальный рабочий ИИ-помощник для Windows, который помогает искать информацию в доступных пользователю системах, работать с изображениями, управлять браузером и выполнять компьютерные задачи.

Проект начинается с чистого репозитория. Этот README описывает целевое направление; перечисленные возможности не следует считать уже реализованными.

## Принятые требования

- Основная ОС на первом этапе: Windows.
- Основной браузер: Яндекс Браузер.
- Браузерная архитектура: гибридная — работа с текущим профилем пользователя через разрешённый мост и отдельное изолированное окно WorkPilot.
- Поиск по фотографиям: как по доступным пользователю локальным/подключённым ресурсам, так и по внешним трекерам, в которые пользователь вошёл самостоятельно.
- Управление компьютером: полноценная автоматизация с контролем разрешений, журналом действий и безопасными границами.
- Приоритет: максимальная автоматизация повторяемых рабочих процессов.
- Целевое оборудование разработчика: 16 ГБ RAM, Intel Core i5-220H и встроенная Intel Graphics. Архитектура должна учитывать ограниченную память и не требовать дискретной GPU.

## Принципы

1. **Local-first:** файлы, история задач, настройки и индекс — локально по умолчанию.
2. **User-session access:** WorkPilot работает только с теми ресурсами, которые пользователь может открыть своей учётной записью и явно подключёнными средствами.
3. **No credential harvesting:** не копировать и не экспортировать cookies, пароли, токены или содержимое профиля браузера в хранилище WorkPilot.
4. **Visible automation:** действия агента должны быть объяснимы, наблюдаемы и записываться в журнал.
5. **Safe autonomy:** обычные обратимые операции автоматизируются; необратимые, финансовые, внешне публикуемые и связанные с безопасностью действия требуют подтверждения.
6. **Memory-aware:** тяжёлые модели и обработчики запускаются по требованию; параллелизм регулируется доступной памятью.
7. **Modular integrations:** сайты и трекеры подключаются через отдельные адаптеры, а не через хрупкую логику в ядре.

## Предлагаемый первый вертикальный срез

Создать минимальный Windows-прототип, который:
1. запускает локальный интерфейс WorkPilot;
2. показывает состояние Resource Manager;
3. подключается к браузерному мосту без извлечения секретов;
4. умеет получить список разрешённых вкладок и сделать скриншот выбранной вкладки;
5. сохраняет локальный журнал действий;
6. проходит базовые тесты и имеет понятную инструкцию запуска.

Сначала проверяем совместимость выбранного способа интеграции с установленным Яндекс Браузером. Не предполагаем, что Chrome API, расширения или remote debugging доступны в нужной конфигурации, пока это не подтверждено тестом.

## Разработка

Изменения следует вести в feature-ветках и объединять через Pull Request. Не добавляйте в репозиторий реальные cookies, пароли, API-ключи, токены, персональные данные или дампы браузерного профиля.
