# WorkPilot

**WorkPilot** — локальный рабочий ИИ-помощник для Windows, который помогает искать информацию в доступных пользователю системах, работать с изображениями, управлять браузером и выполнять компьютерные задачи.

Проект развивается поэтапно. Описанные в архитектуре будущие возможности не следует считать реализованными, пока они не отмечены в дорожной карте и не покрыты проверками.

## Принятые требования

- Основная ОС: Windows.
- Основной браузер: Яндекс Браузер.
- Гибридная браузерная архитектура: текущий профиль через явно разрешённый мост и отдельный изолированный профиль WorkPilot.
- Поиск по фото: локальные/подключённые источники и внешние трекеры через отдельные адаптеры.
- Максимальная автоматизация повторяемых задач с контролем риска.
- Целевое оборудование: 16 ГБ RAM, Intel Core 5 220H, встроенная Intel Graphics.
- Базовое приложение не должно требовать платного API.

## Текущий статус

**Реализован первый backend-прототип (0.1.0):**
- локальный Python Agent Runtime без обязательных сторонних runtime-зависимостей;
- SQLite-хранилище задач и журнала событий;
- Resource Manager с режимами Normal / Economy / Emergency;
- HTTP API, привязанный к loopback и защищённый временным bearer-токеном;
- создание, просмотр и отмена ожидающих задач;
- unit-тесты и GitHub Actions workflow.

**Пока не реализовано:** выполнение задач агентом, desktop UI, управление браузером, интеграция с Яндекс Браузером, поиск по изображениям и локальная языковая модель.

## Запуск на Windows

Требуется Python 3.11 или новее.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m unittest discover -s tests -v
workpilot-agent
```

После запуска агент покажет адрес локального API и временный токен. Не публикуй токен и не отправляй его в чаты. Для остановки нажми Ctrl+C.

Подробности API: [docs/API.md](docs/API.md).

## Безопасность

WorkPilot не извлекает cookies, пароли или токены из браузерного профиля. Агент слушает только localhost. В MVP нет инструментов для управления браузером или компьютером и нет исполнителя задач. Содержимое сайтов и OCR считаются недоверенными данными, а не инструкциями.

## Разработка

Изменения вносятся через feature-ветки и Pull Request. Не добавляйте в Git реальные cookies, пароли, токены, личные данные, дампы браузерных профилей или рабочие выгрузки.
